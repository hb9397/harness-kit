# Harness Kit v0.9.0

`0.9.0`은 portable routing과 쓰기 가드에 Muse 호스트를 정본 편입한 릴리스다.
`harness-kit-muse`는 `0.2.0`으로 정식 빌드 파이프라인에서 생성된다.

## 변경 사항

- Track B 정본에 Muse 라우팅을 추가했다. `.muse/hooks.json` 템플릿과
  `muse-route.py` 어댑터는 공유 routing manifest를 그대로 강제한다. containment,
  정본 문서·앱 소스 허용, 신규 관리물의 one-shot 마커, 외부 기본경로 거부가
  Codex·Claude와 같은 계약으로 동작한다.
- Muse 어댑터 판정은 exit 0+빈 stdout 허용, exit 0과
  `hookSpecificOutput.permissionDecision=deny` 거부다. 미검증 hook 명령, 예외,
  잘못된 payload, routing 부재는 모두 같은 deny로 fail-closed한다.
- `install-routing.ps1`이 `-TargetHost muse`와 `all`의 세 호스트를 다룬다.
  신규·변경 Muse hook은 프로젝트 신뢰 검토 증적 전까지 `pending-trust`다.
- `project-write-access` 가드가 `ai --host muse`를 지원한다. Muse 확인(`ask`)
  응답은 미검증이므로 같은 경우 deny로 fail-closed한다.
- Muse 플러그인 skills는 정본 복사본이며 `allowed-tools` 전면 승인만 제거한다.
  가드는 정본 asset에서 매 빌드마다 vendoring한다.

## 호환성

- 기존 Codex·Claude bundle·installer·trust 동작은 바뀌지 않는다. Muse host
  항목이 추가된 공유 manifest를 읽는 기존 설치는 영향을 받지 않는다.
- Muse `ask` 확인 흐름에 의존하던 프로젝트는 deny로 바뀌므로, 앱 핵심 문서
  편집은 일반 내용·저장 승인과 분리된 명시적 확인을 그대로 유지해야 한다.
- 공개 산출물 계약 변경이므로 `0.x` 기준 minor 버전을 올렸다.
