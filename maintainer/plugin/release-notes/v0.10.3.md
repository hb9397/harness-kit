# Harness Kit v0.10.3

Windows PowerShell 세션에서 Codex `PreToolUse` 시작 명령의 변수가 먼저 치환되어
`Hook failed`와 종료 코드 1이 발생하던 문제를 수정한다.

- Windows 시작 스크립트를 UTF-16LE Base64의 `-EncodedCommand`로 전달한다.
- 설치기는 평문 공통 명령으로 관리 훅을 식별해 재설치·이전 정의 갱신·제거 시
  중복을 방지하고 관련 없는 훅을 보존한다.
- 공백이 있는 하위 경로에서 cmd.exe·PowerShell 7·Windows PowerShell 5.1을 통해
  읽기 허용과 프로젝트 밖 쓰기 거부를 회귀검증한다.
- 기존 프로젝트는 bundle과 Codex 설치 정의를 갱신한 뒤 `/hooks`에서 재검토한다.

보호 자산 영향: 사용자 요청 “수정해서 반영하고 검증” 범위에서
`codex-hooks.json.template`, `install-routing.ps1.template`, bundle README 템플릿과
`skills/harness-setup/evals/run_evals.py`의 내용을 보완한다. 관리자
`plugin_common.py`는 패치 버전을 올린다. 정본 자산의 삭제·이동은 없다.
Codex·Claude runtime과 새 버전 archive는 기존 생성기로 반영한다.
권한·네트워크·산출물 경로·허용/거부 계약은 확대하지 않는다.
