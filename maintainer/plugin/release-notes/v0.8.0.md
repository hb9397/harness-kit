# Harness Kit v0.8.0

`0.8.0`은 portable routing 갱신에 Claude Code의 native `AGENTS.md` 지원을 반영한
하네스 instruction 진입점 정리다.

## 변경 사항

- 새 setup은 `.ai-docs/**`와 루트 `AGENTS.md`만 만들며 `CLAUDE.md` 또는
  `CLAUDE.local.md`를 생성하지 않는다.
- 기존 Claude bridge의 routing·trust 규칙을 `AGENTS.md` 정본으로 합쳤다.
- setup 전에 프로젝트 루트부터 파일시스템 루트까지 `CLAUDE.md`,
  `.claude/CLAUDE.md`, `CLAUDE.local.md`를 검사한다.
- 관리 중인 구형 루트 bridge와 `.ai-docs/root-context/CLAUDE.md`는 `AGENTS.md`를
  먼저 갱신한 뒤 별도 승인으로 제거한다. 사용자 내용이 섞였거나 상위 경로에 있는
  instruction 파일은 자동 삭제하지 않고 중단한다.
- 프로젝트 공유 산출물에서 설치 PC 절대경로, 사용자명, checkout 폴더명 결합을 제거하고
  host 상태를 Git 무시 대상인 `.ai-docs/.harness/routing-state.local.json`으로 분리했다.

## 호환성

이 버전의 AGENTS-only Claude 계약은 Claude Code `2.1.277` 이상을 요구한다. 공식 문서가
명시한 Bedrock·타사 provider·telemetry 비활성화 등 native 지원 예외 환경에서는 기존
Claude instruction 파일을 임의로 제거하지 말고 setup 중단 결과에 따라 별도 운영 결정을
내려야 한다. `CLAUDE.md` 출력 제거는 `0.x` 기준 breaking change이므로 minor 버전을 올렸다.
