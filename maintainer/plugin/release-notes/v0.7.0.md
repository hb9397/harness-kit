# Harness Kit v0.7.0

`0.7.0`은 프로젝트 공유 산출물에서 설치 PC와 checkout 이름 결합을 제거하는
portable routing 갱신이다.

## 변경 사항

- `.ai-docs/harness/artifact-routing.json`의 `project_root`를 `.`으로 고정하고 host별
  설치·신뢰·config hash를 Git 무시 대상인
  `.ai-docs/.harness/routing-state.local.json`으로 분리했다.
- Codex managed hook은 설치 당시 절대경로 대신 session cwd의 상위에서 프로젝트 hook을
  찾는다. 다른 위치에 clone하거나 checkout 폴더명을 바꿔도 같은 설정을 사용할 수 있다.
- 루트 context 제목·루트 표기와 단일 앱 fallback id가 checkout 폴더명에 의존하지 않는다.
- 이미지·PDF 등 fixed-format `_inbox` manifest는 원본 basename과 SHA-256만 기록하고
  사용자 PC의 `source_path`를 기록하지 않는다.
- 문서 개선 handoff id에서 프로젝트 절대경로를 제거했고, 예제의 특정 사용자·프로젝트
  식별자를 일반 fixture로 교체했다.
- `harness-setup` update mode가 기존 절대경로 manifest·hook·context를 portable 형식으로
  이관하고, 기존 handoff id와 알려진 구버전 routing 파일까지 정리한 뒤 다른 checkout에서
  공유 산출물이 동일한지 검증한다.

## 호환성

공유 routing schema는 `1.2.0`이다. 기존 `1.1.0`의 앱·repository 계약은 유지하며,
host 상태만 PC별 로컬 파일로 이동한다. 기존 `0.6.x` archive와 증적은 변경하지 않는다.
