# Harness Kit v0.6.5

`0.6.5`는 `0.6.4`의 회귀 검증이 Linux CI에서 실패하던 문제를 바로잡는 패치다.

## 변경 사항

- `harness-setup` eval이 `powershell.exe`를 실행 가능한 환경에서만 Windows PowerShell 5.1
  경로를 검증한다. `pwsh`만 있는 Linux CI에서는 해당 shell 조합을 건너뛴다.

## 호환성

`0.6.4`의 Codex·Claude PreToolUse 훅 응답 규격과 matcher는 그대로다. 기존 `0.6.4` archive와
증적은 변경하지 않는다.
