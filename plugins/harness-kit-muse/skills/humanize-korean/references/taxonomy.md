# Korean AI/Translationese Refinement Taxonomy

`im-not-ai` v2.3.0의 핵심 방향을 하네스 문서용으로 축약·재구성한 참고 분류다.

| ID | 유형 | 점검 포인트 |
|---|---|---|
| A | 번역투 | `~에 의해`, `~에 있어서`, `~를 통해` 남용 |
| B | 과한 명사화 | 동사로 풀 수 있는 `수행`, `진행`, `처리` 반복 |
| C | 기계적 병렬 | `첫째/둘째/셋째`, 동일 길이 문장 반복 |
| D | AI 관용구 | `결론적으로`, `시사하는 바가 크다`, `중요한 역할을 한다` |
| E | 피동·사동 남용 | 주체가 사라진 문장 |
| F | 과도한 완곡 표현 | 책임·의무 수준이 흐려지는 표현 |
| G | 문서 리듬 불균형 | 모든 문장이 비슷한 길이와 구조로 반복 |

이 분류는 진단 보조용이다. 분류에 맞춘다는 이유로 의미나 요구사항을 바꾸면 안 된다.

## 문맥 의존 표현 판정

v2.3.0의 핵심은 **탐지된 span만 수술적으로 다루고, 탐지 근거가 없는 구간은
건드리지 않는 것**이다. 위 표의 표현은 금칙어 목록이 아니다.

| 표현 | 먼저 확인할 것 | 제안 방식 |
|---|---|---|
| `~를 통해`, `~을 통해` | 실제 수단인지, 이동 경로·매개가 핵심인지 | 수단이면 `로/으로`, 주체가 분명하면 능동문을 후보로 제시한다. 경로 의미가 정확하면 유지한다. |
| `~에 의해` | 행위 주체가 확인되는지, 법률·학술상 정확한 피동인지 | 주체가 확인될 때만 능동문을 제안한다. 조사만 `가/이`로 바꾸지 않는다. |
| `결론적으로` | 빈 결말 공식인지, 앞선 근거를 실제로 요약하는지 | 기능 없는 표지면 삭제를 제안한다. 논리적 요약 기능이 있으면 유지하거나 문맥에 맞는 연결어를 후보로 둔다. |

진단 결과는 `category`, `span`, `line`, `reason`, `suggestions`를 포함한다.
후보 선택과 실제 윤문은 문단 전체 의미를 판단할 수 있는 에이전트가 수행한다.
deterministic 보조 스크립트는 이 세 표현을 직접 치환하지 않는다.
